## 📌 Overview

This repository provides a structured collection of Linux concepts and commands, progressing from basics to advanced system-level operations.
It focuses on **practical usage**, not just theory — aligned with real DevOps workflows.

## 🧠 Topics Covered 

### 📘 01 - Getting Started

* Introduction to Linux and distributions
* Basic terminal usage
* Essential command-line concepts

### 📁 02 - Folder Structure

* Linux directory hierarchy (`/`, `/home`, `/etc`, `/var`, etc.)
* Understanding system layout and file organization

### 👤 03 - User Management

* Creating and managing users/groups
* Password policies and account control
* Sudo access and privilege management

### 📄 04 - File Management

* File operations (`cp`, `mv`, `rm`, `find`)
* Viewing and editing files
* Text processing (`grep`, `awk`, `sed`)

### 📝 05 - VI Editor Shortcuts

* Navigation and editing in `vi`/`vim`
* Insert, command, and visual modes
* Productivity shortcuts for DevOps workflows

### 🔐 06 - File Permissions

* Permission model (`rwx`)
* Ownership (`chown`, `chgrp`)
* Special permissions (SUID, SGID, Sticky Bit)

### ⚙️ 07 - Process Management

* Managing processes (`ps`, `top`, `kill`)
* Foreground/background jobs
* Process troubleshooting

### 📊 08 - Monitoring

* System performance monitoring
* Resource usage (CPU, memory, disk)
* Tools like `top`, `htop`, `free`, `uptime`

### 🌐 09 - Networking

* Network troubleshooting tools (`ping`, `curl`, `ss`, `netstat`)
* DNS resolution and connectivity checks
* Basic network configuration

### 💾 10 - Disk Management

* Disk partitioning and mounting
* Filesystems and storage handling
* Disk usage analysis (`df`, `du`, `lsblk`)

### 🐚 11 - Bash Scripts Collection

* Bash scripting fundamentals
* Automation scripts for real-world tasks
* Variables, loops, and conditionals

### 📚 12 - Cheatsheets

* Quick reference for commands
* Interview-focused summaries
* DevOps daily-use command shortcuts
